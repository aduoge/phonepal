# 用 TRAE 搭建你的个人 Agent 助手：学生动手手册

两节课，带你把小满装进安卓手机，再用 TRAE 把它改成你想要的样子。第一节装好、用起来；第二节让它更懂你，并亲手给它改一处。读代码、改代码、跑命令都交给 TRAE，你负责把需求说清楚，再到手机上看结果对不对。

> 本手册对应直播讲义。讲义里有录屏和图解，这里只保留你要动手做的部分。

## 课前准备

手机自动操作需要 **Android 11 及以上**。iPhone 不支持：小满靠安卓的无障碍服务读屏幕、点按钮，iOS 不允许普通 App 读取或操作其他 App。只有 iPhone 的同学可以跟着学 TRAE 部分，手机实操和安卓同学结对。

### 1. 开通火山方舟，拿到 API Key

1. 注册火山引擎账号，完成实名认证。
2. 进入方舟控制台，开通模型。讲师用的是 `doubao-seed-2-1-pro-260915`。小满要填两个模型：聊天模型和操作模型，操作模型要能看图，用同一个也行。
3. 创建 API Key，只填进手机 App，不要发到群里、写进代码或截图公开。
4. 记下 Base URL：`https://ark.cn-beijing.volces.com/api/v3`（App 里默认就是它）。
5. 看一眼免费额度、推理限额和“安心体验”开关。

用别家模型也可以，只要兼容 OpenAI 接口、有 Key 和 Base URL，比如阿里云百炼、OpenRouter。

### 2. 电脑

| 要装什么 | 怎么装 | 怎么确认装好了 |
|-|-|-|
| TRAE IDE | 官网下载安装并登录 | 能打开课程文件夹，能用 TRAE 终端 |
| Python 3.8 及以上 | Windows：python.org 下载，安装时勾选 Add python.exe to PATH。macOS：一般自带 python3 | 终端运行 `python --version`（macOS 用 `python3 --version`） |
| Android platform-tools | 从 Android 官网下载解压，把目录加进 PATH；macOS 也可以 `brew install android-platform-tools`。不会配就让 TRAE 帮你 | 手机连上后运行 `adb devices -l`，显示 `device` |
| JDK 17、Android SDK 35（选装） | 只有想自己构建 APK 的同学需要；课前运行一次 `scripts/gradle.sh --online test :app:assembleDebug` 下载依赖 | 构建成功；普通同学直接用课程 APK |

为什么要装 Python 和安卓工具？TRAE 改完技能，要在电脑上校验、再推送到手机；改了程序，还要构建新的安装包。装好这两样，TRAE 才能自己跑完、自己检查。

### 3. 手机

1. **安装 APK**，两种方式任选：用手机浏览器打开课程材料包里的下载链接；或者把电脑上的 APK 用数据线、微信或飞书文件助手传到手机。按提示允许“安装未知来源应用”，vivo 等机型弹出风险提示时勾选“已了解风险”。
2. **填模型**：打开小满「设置」，聊天模型和操作模型各填一遍 Base URL、模型名（或接入点 ID）、API Key。
3. **开权限**：开启“小满”无障碍服务和通知；想要后台提醒，再开后台运行权限（vivo：设置 → 后台耗电管理 → 小满 → 允许后台高耗电）。
4. **开 USB 调试**（第二节要用）：设置 → 关于手机，连续点“版本号”7 次打开开发者选项，再打开 USB 调试；连电脑后在手机上点“允许”。`adb` 显示 `unauthorized` 就去手机上确认，显示 `offline` 就重插数据线。
5. **登录要用的 App**：第一节登录淘宝；第二节登录美团和 12306，提前完成滑块、实名和手机核验，确认常用乘车人。

### 4. 课前自检

- [ ] 在小满里发一句闲聊，有回复：聊天模型通了。
- [ ] 说“打开设置里的 Wi-Fi 页面”，手机自己跳过去：操作模型和无障碍也通了。
- [ ] 在 TRAE 终端里进入 xiaoman 源码文件夹，`adb devices -l` 显示 `device`，`python cli/xiaoman.py lint skills/examples/*` 显示 `0 problem(s)`。

## 第一节：把助手用起来

### 用 TRAE 打开源码

解压课程材料包，用 TRAE 打开 `xiaoman` 源码文件夹，在对话框里发：

```text
请阅读这个项目的 README.md 和目录结构，用不懂代码的人也能听懂的话告诉我：
1. 聊天、记忆、技能、手机操作这四块分别在哪个文件夹；
2. 我在手机上说一句话之后，程序大概经过了哪几步；
3. 如果以后想改助手的某个习惯，通常改哪里。
先只讲解，不要修改任何文件。
```

### 一句话跑通淘宝任务

确认淘宝已登录，在小满里发：

```text
帮我在淘宝挑一本20元以内的A5笔记本，选好后给我确认。
```

它弹出确认时，看清楚再点“允许一次”。停下来以后，对照结算页核对店铺、规格、数量和金额。遇到滑块或验证码，自己手动通过，再回到小满说“继续”；实在过不去，先做下面的提醒练习。

助手说“已完成”不算数，手机页面上看到的才算数。停在结算页叫“准备好了”，不能说成“已经买了”。

### 记一条偏好，设一次提醒

```text
记住：我买东西喜欢简单实用的款式。
```

打开 App 的「记忆」页，能看到这一条。记忆是 Markdown 文件，存在手机的小满应用目录里；说“忘记……”会删除对应文件。

```text
2分钟后提醒我喝水。
```

发完把小满切到后台，等通知弹出来。当前是非精确定时，可能晚一分钟左右，别拿它当必须准点的提醒。

### 第一节作业

- 必做：装好环境，发起一条你自己写的任务，交需求原文和结果截图。
- 选做：设置一条偏好，截图记忆页。
- 没跑通也可以交：截图卡住的页面，写一句停在哪一步。

提交到 TRAE 论坛，标签选“训练营课堂作业”。截图里的地址、手机号、收货人和 Key 记得打码。

## 第二节：用 TRAE 优化你的助手

### 蒸馏你自己，让它记住你

**蒸馏**是整理你怎么做事：常做哪些事、说话什么风格、底线在哪。**记住**是保存关于你的长期事实，比如家里地址、常用手机号，以后下单、填表时它直接帮你填。两件事都不训练模型。

写下 3 条偏好、2 件常做的事、1 条底线，交给 TRAE：

```text
下面是我的 3 条偏好、2 件常做的事和 1 条底线：
（贴上你写的内容）
请帮我整理成一份助手能用的个人档案：每条偏好写成一句清楚的规则，并给一个例子；
常做的事写成“我说什么 → 希望它怎么做”；底线单独列出。
不要加入我没提到的信息，地址和手机号先不要写进去。
```

逐条确认后，一条条告诉小满，比如“记住：买东西先看评价，预算宁低勿高”。地址、手机号直接在手机上告诉小满，不要放进要分享的作业材料。然后换个问法验证，再试一次“今天帮朋友买，预算放宽到 200”，当次要求应该优先于默认偏好。

### 改造循环与六个习惯

用 → 选 → 说 → 验 → 记：用几天记下卡点，挑一个最小改动，把需求交给 TRAE，装到手机上看结果，留档后下一轮接着改。改技能（SKILL.md）推送后马上生效；改程序要重新构建并安装 APK。

1. **需求写清四件事**：想要什么、一个具体例子、不能做什么、怎么算完成。
2. **先问后改**：陌生代码先让 TRAE 讲结构和改动位置，看懂再动手。
3. **一次一件事**：一次只改一处，改之前留一份能退回去的版本。
4. **让它交代清楚**：改了哪些文件、校验或构建结果、要你实测的步骤。
5. **以手机上的结果为准**：页面和通知要亲眼看到才算数。
6. **报错原样给**：报错、截图和你做过的步骤一起发，先让它分析原因。

### 场景 A（生活）：外卖按你的口味筛

先在小满里试一次：

```text
我一个人吃，30 元以内，想吃鸡肉饭，不辣。按当前配送区域先找两家，告诉我页面上的价格条件和预计送达时间，暂不加购。
```

再交给 TRAE：

```text
请阅读 README.md、docs/skills.md 和 skills/examples/meituan-takeout-order，
先用简单的话解释聊天模型、技能和手机操作怎样合作。
然后帮我增加默认筛选条件：不推荐含糖饮料；默认只选页面预计 40 分钟内送达的餐，
如果没有就告诉我，不自动放宽。当次明确要求可以覆盖默认条件。
保留预算计算、购物车处理和订单确认机制，运行技能校验并解释改动。
```

```bash
python cli/xiaoman.py lint skills/examples/meituan-takeout-order
python cli/xiaoman.py push skills/examples/meituan-takeout-order
```

看到 `0 problem(s)` 和 `skills reloaded` 后，把同一句需求再发一次，对比改前改后。macOS 没有 `python` 就改用 `python3`。

### 场景 B（工作）：出差查高铁，到点提醒

```text
帮我查明天上海虹桥到杭州东、18 点后出发的二等座，先核对价格和余票，再打开预订页。先不要选择乘车人、提交订单或付款。
```

它点“预订”前会弹确认，核对车次后点“允许一次”。到确认订单页后再说：

```text
根据我刚才确认的行程，帮我设置出门提醒。先确认具体提醒时间，再设置，不要根据猜测的车次安排。
```

需求里多给一个关键条件（比如具体出发时间），它会少走很多弯路。然后交给 TRAE：

```text
请阅读 skills/examples/train-ticket-order，增加一条规则：
推荐车次时优先直达、并且一小时内到达的；没有满足条件的就先告诉我，不要自动放宽。
日期不清楚时先问我，不能混淆城市和具体车站、有票和候补。
保留“选定车次后才准备订单、乘车人由我确认、付款由我完成”的流程，完成后运行 lint 并解释改动。
```

```bash
python cli/xiaoman.py lint skills/examples/train-ticket-order
python cli/xiaoman.py push skills/examples/train-ticket-order
```

换一条你真要去的路线再验证一次，日期和票价以当天可售为准。

### 场景 C（改 App）：给首页加快捷入口

```text
请在小满首页新增“找一根充电线”卡片，点击后在输入框填入
“帮我在淘宝挑一根30元以内的Type-C充电线，选好后给我确认。”
文字保持可编辑，由用户点击发送后才执行。参考现有卡片的样式。
完成后说明改了哪些文件，运行测试并构建 APK，告诉我怎么装到手机上验证。
```

构建成功后，手机连着电脑执行 `adb install -r <APK 路径>` 覆盖安装；没装构建环境的同学用讲师课后发的新版 APK。验收三件事：首页能看到卡片；点了以后文字填进输入框且可以改；不点发送它不会动。

### 出错了，怎么让 TRAE 修

```text
我的目标是……，实际停在……。这是本次运行 ID、最后几步日志和当前截图。
请先解释失败在哪一步，再写能复现问题的测试，然后做最小范围的修改。
保留成功标准，不能把没做完改成成功。修改后告诉我怎么校验、安装和重新验证。
```

单独调试操作层可以用：

```bash
python cli/xiaoman.py run "在美团外卖搜索鸡肉饭，比较两家候选，不加购、不下单" --skill meituan-takeout-order --follow
python cli/xiaoman.py traces show 本次运行ID
python cli/xiaoman.py stop
```

## 课后：自己接着改

| 方向 | 交给 TRAE 的一句话 | 怎么算改好了 |
|-|-|-|
| 更懂你 | 帮我把这份个人档案整理成助手能用的偏好条目，告诉我存在哪里、以后怎么改。 | 换个问法也能用上偏好；当次要求能覆盖默认。 |
| 更像你 | 把助手的名字改成我喜欢的，再换一套主题色；告诉我哪些地方会显示新名字。 | 桌面图标、聊天页、通知和无障碍列表里都是新名字。 |
| 少重复 | 参考现有技能，把“每周买一次牛奶”写成技能，写清步骤、哪里要我确认、怎么检查结果。 | 连跑 3 次结果一致；页面变了会停下说明。 |
| 更顺手 | 在首页加一个“查快递”快捷卡片，点击后填入可编辑的需求，由我点发送。 | 卡片可见、文字可改、点发送才执行。 |
| 更放心 | 列出现在哪些动作会先问我；把付款、删除、对外发消息都加进来，并说明怎么判断的。 | 用示例数据试一次删除，能停在确认前。 |

## 常见问题

- **没写过代码能学吗？** 能。代码交给 TRAE，你负责说清需求、看手机上的结果。
- **要部署服务器吗？** 不用。Key 填进手机 App 就能用，记忆也存在手机上。
- **它会自己付款吗？** 不会。支付、发送、删除前都会弹确认；密码框它不能输入。
- **报 429 SetLimitExceeded？** 账号额度或限额问题，去方舟控制台检查推理限额、“安心体验”和余额。
- **说“已设置提醒”但没弹？** 检查通知和后台运行权限；允许晚一分钟左右。
- **能用手机控制电脑吗？** 这一期不做。
- **多台手机连着电脑？** 命令后面加 `--serial 设备序列号`，序列号用 `adb devices -l` 查。
