# 设置闹钟

目标：在手机自带的时钟 App 里**新建**一个闹钟，响铃时间来自用户的话；不编辑、不删除、不开关任何已有闹钟。

1. 先结合当前日期和时间，把用户说的时间换算成具体的日期和时刻（能处理「明早 7 点」「下周一 8 点半」这类说法）。
   - 时刻、上午/下午、日期里任何一项不确定（例如只说「7 点」），用 ask_user 问清楚，不要猜，也不要自行默认上午。
   - 换算出的时刻今天已经过去时，按最近一次未来时间理解（次日或下一个对应日期）；有歧义就先 ask_user 确认。
2. 启动系统自带的时钟 App（多数机型包名 com.android.deskclock，Pixel 等为 com.google.android.deskclock），进入底部「闹钟」页。
3. 点「+」新建闹钟，在时间选择器上设好第 1 步确定的时刻；用户没要求重复时不要开重复，不要改铃声、标签等其他设置。
4. 保存前核对页面显示的响铃日期时间或「N 小时后响铃」提示与用户要求一致；不一致就改，改不了用 ask_user 说明情况。
5. 点「确定」/「保存」。全程不要点已有闹钟的开关，不要进入已有闹钟的编辑页；看到「删除」「批量管理」之类入口不要点。

完成后 finish，summary 写新闹钟的响铃日期和时间。找不到时钟 App 或反复无法设好时，用 ask_user 询问或 finish 且 success=false 说明原因。
