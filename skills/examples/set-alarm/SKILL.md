# 设置闹钟

目标：在手机自带的时钟 App 里**新建**一个闹钟，响铃时间来自用户的话；不编辑、不删除、不开关任何已有闹钟。

1. 先根据任务中给出的日期时间，或屏幕上可核对的当前日期时间，把用户说的时间换算成具体的日期和时刻；缺少依据时用 ask_user 问清楚。
   - 时刻、上午/下午、日期里任何一项不确定（例如只说「7 点」），用 ask_user 问清楚，不要猜，也不要自行默认上午。
   - 换算出的时刻今天已经过去时，按最近一次未来时间理解（次日或下一个对应日期）；有歧义就先 ask_user 确认。
2. 启动系统自带的时钟 App（原生 Android 为 com.android.deskclock，Pixel 等为 com.google.android.deskclock，vivo 为 com.android.BBKClock），进入底部「闹钟」页。根据实际机型选择；启动失败后再尝试列表中的其他包，不要凭包名假定已启动成功。
3. 点「+」新建闹钟，在时间选择器上设好第 1 步确定的时刻；用户没要求重复时不要开重复。用户明确给出标签时使用该标签；未要求时保留默认标签和铃声等其他设置。
   - 时间控件如果支持直接输入，优先直接输入。使用滚轮时，先看中间选中的数字和上下相邻数字，每次滑动后重新读数。
   - 距目标只差 5 格以内时，逐格微调：滑动距离先取两个相邻数字间距的一半，再按读数变化调整。vivo 时钟的滚轮数字可能不响应点击，应使用小幅滑动；其他机型尝试点击一次后读数不变，也立即改为滑动。接近目标后不要继续大幅滑动。
   - 记录上次滑动造成的变化；一旦越过目标，缩短距离。两次往返越过目标后仍不会微调，就 ask_user 说明卡在时间选择器，不要重复相同的大幅滑动。
4. 保存前核对页面显示的响铃日期时间或「N 小时后响铃」提示与用户要求一致；不一致就改，改不了用 ask_user 说明情况。
   - 若 App 只能设置下一次响铃，不能指定用户要求的未来日期（例如下周一），先向用户说明限制，不要用每日或每周重复冒充一次性闹钟。
5. 点「确定」/「保存」。全程不要点已有闹钟的开关，不要进入已有闹钟的编辑页；看到「删除」「批量管理」之类入口不要点。

完成后 finish，summary 写新闹钟的响铃日期和时间。找不到时钟 App 或反复无法设好时，用 ask_user 询问或 finish 且 success=false 说明原因。
