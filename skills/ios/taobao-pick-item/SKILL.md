# 淘宝挑选商品，停在确认订单页

1. 用 `launch` 启动淘宝，bundleId 为 `com.taobao.taobao4iphone`。从用户目标提取商品、预算和规格要求；缺少预算或关键规格时用 `ask_user` 询问，不猜测。
2. 搜索商品，对照名称、规格、价格和用户要求挑选。避开预售、订金、合约、订阅、以旧换新及其他附带条件；找不到合适商品时说明原因并 `finish`。
3. 选择符合目标的普通规格，数量为 1。不要加入、删除或修改购物车，不修改收货地址；现有地址缺失或无法配送时用 `ask_user` 请用户接管。
4. 商品与规格确认后，可通过「立即购买」进入确认订单页。若 Sentinel 请求确认，等待用户明确授权；授权只用于进入核对页面。
5. 在确认订单页核对商品名称、规格、数量 1、运费和合计金额。合计必须在预算内；优惠或价格不明确时向用户说明，不能按宣传价猜测。
6. 不点击「提交订单」「付款」「支付」或其他会创建订单、扣款的按钮，即使此前已获本次任务授权也在此停止。用 `finish` 汇报商品、规格、合计及是否符合预算，说明已停在确认订单页，尚未提交订单。
7. 任意步骤遇到登录、密码、验证码、滑块、身份验证或不可读页面，立即用 `ask_user` 请求接管（`takeover: true`），由用户手动处理后再继续。不要记录或复述密码、验证码和地址。
