手机打不开怎么办
  • 确认手机没开流量代替 Wi-Fi，并且和电脑是同一个 Wi-Fi 名称。
  • Windows 第一次启动会弹出防火墙提示，要勾选“专用网络”并点“允许访问”。
  • 公司、学校、酒店的 Wi-Fi 常常禁止设备互相访问：打开手机热点，让电脑连上这个热点，再点“刷新地址”重新扫码。
  • 实在不行，先点“先在电脑浏览器里试用”，在电脑上练习也一样。
